# Local Assets Guide

This file provides information about the local assets that should be placed in the respective directories to replace the previous Cloudinary references.

## Required Asset Files

### Service Images
Place these GIF/WebP files in `/public/Images/services/`:
- `bbbp-service.gif` - Blood-Brain Barrier Permeability service icon
- `binding-score-service.gif` - Binding Score service icon
- `cox2-service.gif` - COX2 service icon
- `hepg2-service.webp` - HEPG2 service icon
- `cyp3a4-service.gif` - CYP3A4 service icon
- `half-life-service.gif` - Half Life service icon
- `solubility-service.gif` - Solubility Checker service icon
- `ace2-service.gif` - ACE2 service icon
- `toxicity-service.gif` - Toxicity service icon

### Feature Images
Place these JPG files in `/public/Images/features/`:
- `solubility-prediction.jpg` - Solubility Prediction feature image
- `bbb-permeability.jpg` - Blood-Brain Barrier Permeability feature image
- `target-identification.jpg` - Target Identification feature image
- `molecular-docking.jpg` - Molecular Docking feature image

### Video Files
Place these MP4 files in `/public/Images/videos/`:
- `pricing-background.mp4` - Background video for pricing page
- `blog-background.mp4` - Background video for blog page
- `chatbot-icon.mp4` - Animated icon for chatbot

## Notes
- All image and video files should be optimized for web use to ensure fast loading times
- Consider using WebP format for better compression and quality
- Ensure that video files are compressed appropriately for web use
